Deployment policy templates are yours to edit. The hard floor is code, shown read-only.

Template default policy

This is the template default that ships with the apps. When a customer deploys one of the platforms, this file is the starting policy file bundled with the template. They can edit it per deployment later, and so can you, per repo, from the repo list. It controls only the soft policy layer: an empty entry list means no soft blocks. The hard floor is separate code and is not part of this file.
